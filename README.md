# 🧩 LeetCode Java Solutions

Este repositório é dedicado à organização e acompanhamento da resolução de problemas da plataforma **LeetCode** utilizando a linguagem **Java**. 

O objetivo principal deste projeto é o aprimoramento contínuo em **algoritmos**, **estruturas de dados**, **análise de complexidade (Big O)** e **lógica de programação**.

---

## 📁 Estrutura e Padronização do Repositório

Para manter o repositório escalável e facilitar a execução local em qualquer IDE (como **IntelliJ IDEA**, **Eclipse** ou **VS Code**), cada solução é implementada em seu próprio arquivo contendo:

1. **A Solução do LeetCode:** A classe e o método contendo a lógica exigida para passar nos testes da plataforma.
2. **O Método de Teste (`main`):** Uma estrutura pronta e autossuficiente para executar os casos de teste diretamente na máquina local, permitindo depuração e verificação rápida via console.

As soluções são organizadas em diretórios categorizados pelo nível de dificuldade do problema:

```text
├── src/
│   ├── easy/
│   ├── medium/
│   └── hard/
└── README.md
```

---

## ⚙️ Como Executar os Testes na IDE

1. **Clonar o Repositório:**
   ```bash
   git clone https://github.com/lxzinxs/leetcode
   ```

2. **Abrir o Projeto:**
   * Importe a pasta do repositório em sua IDE de preferência.
   * Certifique-se de ter o **JDK** configurado no ambiente.

3. **Executar um Exercício:**
   * Navegue até o arquivo da questão desejada no diretório correspondente.
   * Execute o método `main` da classe para rodar as validações e visualizar as saídas no terminal.
